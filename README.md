# Student Repository - Odoo Addons

This repository contains Odoo addons for educational management.

## Modules

### Student Course Management (`student_course`)

A complete student course management system with reporting capabilities.

**Features:**
- Student management (profile, contact information)
- Course management (course details, credits, instructors)
- Enrollment tracking (link students to courses)
- PDF Report generation for student enrollments

See the [student_course README](student_course/README.md) for detailed documentation.

## Installation

1. Clone this repository to your Odoo addons directory
2. Update the addons list in Odoo
3. Install the desired module(s)

## Usage

After installation, access the modules through the Odoo interface:
- **Student Management** menu for the student course module
